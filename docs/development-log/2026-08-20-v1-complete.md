## 二、專案動機

這個 App 是從自己的生活痛點出發，希望解決「知道自己應該學習，但很難長期維持學習動力」的問題。

因此沒有單純設計成 Todo List，而是加入：

- AI 目標拆解
- 學習地圖
- 每日打卡
- 遊戲化 XP
- 寵物成長
- 朋友共學

希望讓學習變成比較有持續性的體驗。

## 三、開發方式

這次開發過程使用 AI 作為輔助工具。

目前主要使用：

- Gemini：協助整理想法與 Prompt
- Cursor：協助實作程式
- Git / GitHub：版本控制與保存開發歷程

## 四、目前使用的技術

- React
- TypeScript
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Cloud Functions
- Gemini API

## 五、目前發現的問題

V1 完成後進行程式碼審查，發現部分 Firestore / Storage 權限規則仍需要進一步改善。

另外也發現部分資料操作雖然使用了 transaction 的概念，但實際實作仍需要重新確認資料一致性。

## 六、這次最大的學習

這次讓我開始理解：

> App「可以運作」和「系統設計正確」是兩件不同的事情。

一開始比較重視功能是否能完成，但在 V1 Review 後，開始注意資料權限、安全性、資料一致性與系統架構。
